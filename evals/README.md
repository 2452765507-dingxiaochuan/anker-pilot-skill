# Anker Pilot V6 · Skill 评测集

这一组测试题用于考试前检查 Skill 是否真的提高结果，而不是只让 Prompt 变长。方法参考 Anthropic Skill Creator 的“代表性测试题 + 明确验收 + 迭代”思想，测试内容为本项目独立编写。

## 使用方法
1. 选 3–5 个测试题。
2. 同一题分别用“不开 Skill”和“开 V6 Skill”完成。
3. 用 `test-cases.json` 中的 assertions 逐项检查。
4. 特别记录：事实错误、遗漏硬要求、模板化方案、视觉失败、执行不可落地、语言冗余。
5. 只修改真正导致失败的 Prompt / case pack，不为了长度继续扩写。

## 核心评价维度
- **问题判断**：是否先找根因与约束；
- **证据质量**：事实、假设、来源是否清楚；
- **安克相关性**：是否合理使用公司资产，而非硬贴 One Anker；
- **专业完整度**：专项独有问题是否覆盖；
- **选择能力**：是否给推荐和取舍；
- **执行性**：负责人、时间、资源、验证、调整信号；
- **视觉质量**：页面是否有明确设计方向和信息主次；
- **语言质量**：自然、具体、无模板套话；
- **验证**：是否实际检查文件和关键事实。
