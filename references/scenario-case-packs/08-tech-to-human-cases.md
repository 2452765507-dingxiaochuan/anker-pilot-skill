# 3H｜科技语言 → 用户语言案例素材包

## Dyson V15 Detect｜把“不可见”变成“可见证据”
来源：https://www.dyson.com/content/dyson/us/en/newsroom/news/product/v15-detect-launch
- 激光让微尘可见，piezo sensor 把颗粒计数显示到屏幕上。
- 技术传播从“更强算法/传感器”变成“我能看到以前看不到的脏，并看到清洁证据”。
- **可迁移**：复杂技术优先设计一个用户能看到、听到、比较或操作的证明。

## Dyson Demo Store｜技术解释与现场体验绑定
来源：https://www.dyson.com/discover/innovation/rethinking-technology/reinventing-retail-virtual-dyson-demo-store
- 技术故事由 expert + hands-on demo 共同完成。
- **可迁移**：技术文案、媒体材料、销售演示、线下 Demo 应共享同一套证据链。

## Samsung 837｜从 spec 转成兴趣场景
来源：https://news.samsung.com/us/zach-overton-evolution-of-retail-how-brands-can-stay-relevant-and-drive-growth-in-the-digital-age/
- 通过 cooking / film / art / music 等兴趣让技术进入用户生活。
- **可迁移**：技术传播先找到用户已经关心的事情，再把技术作为改善体验的机制。

## Anker Berlin｜跨设备协同要通过整体场景理解
来源：https://www.anker-in.com/posts/ifa2026
- 通过 real life arrangement 与跨品类演示解释一个 hub、camera、robot vacuum 如何共同工作。
- **可迁移**：生态类技术传播不要让用户自己拼图，要直接演示“多个产品一起解决一个生活任务”。
