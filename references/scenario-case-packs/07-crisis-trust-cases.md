# 3G｜危机 / 信任修复案例素材包

## Samsung Galaxy Note7｜行动优先于修辞
官方初始声明：https://news.samsung.com/global/statement-on-galaxy-note7
监管召回：https://www.cpsc.gov/Recalls/2016/Samsung-Recalls-Galaxy-Note7-Smartphones
停止销售与使用：https://news.samsung.com/us/official-statement-global-stop-sale-and-exchange-of-galaxy-note7/
根因发布会：https://news.samsung.com/global/samsung-electronics-announces-cause-of-galaxy-note7-incidents-in-press-conference
- 先停止销售/召回、给用户明确行动，再持续更新调查；后续公开根因，并引入第三方测试机构。
- **可迁移**：安全/合规问题的第一优先级是降低继续伤害的概率；沟通围绕“事实—行动—补救—验证—更新时间”展开。
- **注意**：过早宣布问题已经解决会扩大二次风险；替换产品再次出现问题就是典型提醒。

## 危机恢复关键原则
- 用户下一步要做什么必须非常清楚。
- 时间线和已知/未知边界公开。
- 事实变化时及时更新，不用旧声明维护面子。
- 技术/安全争议尽量引入独立验证。
- 结束危机沟通前，要有产品/流程层的改进证据。
