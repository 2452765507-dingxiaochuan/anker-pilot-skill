# 3E｜PR / 媒体 / 发布会案例素材包

## Anker IFA 2026｜一个事件里组织多层新闻价值
来源：https://www.anker-in.com/posts/ifa2026
- One Anker 品牌统一、Berlin store、MindBase、THUS 与多个新品形成不同媒体切口。
- **可迁移**：企业级发布会要同时准备公司战略、行业趋势、产品技术、消费者体验、当地市场等不同叙事入口。

## Apple Newsroom / Retail Openings｜用具体事实让设计故事可报道
来源：https://www.apple.com/newsroom/2025/09/the-all-new-apple-ginza-opens-this-friday-september-26-in-tokyo/
- 设计、材料、能源、可访问性、Today at Apple、服务空间都有具体事实与图片支撑。
- **可迁移**：媒体包优先提供“可以直接核验和引用的事实”，再谈形容词。

## Dyson V15 Detect｜工程事实转新闻故事
来源：https://www.dyson.com/content/dyson/us/en/newsroom/news/product/v15-detect-launch
- 用“看不见的灰尘如何被看见”和传感器实时计数，把复杂技术变成清楚的可视化故事。
- **可迁移**：科技 PR 的核心资产包括可演示现象、研发过程、关键数据和用户后果。

## Samsung Note7 根因发布会｜高风险议题需要第三方证据
来源：https://news.samsung.com/global/samsung-electronics-announces-cause-of-galaxy-note7-incidents-in-press-conference
- 根因说明邀请 UL、Exponent、TÜV Rheinland 等独立机构共同呈现调查。
- **可迁移**：重大信任问题的 PR 不应只靠公司声明，第三方验证与可复查方法更有价值。
