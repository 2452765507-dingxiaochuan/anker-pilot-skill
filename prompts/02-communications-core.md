# 02｜传播推广专业加固（3 个 Prompt）

> 只在题目涉及品牌、传播、营销、内容、媒体、用户沟通或市场推广时使用。它负责补充专业判断，不重新跑一遍通用流程。

## 1｜传播课题 + 受众变化
```text
请站在资深品牌传播负责人的角度，对当前业务诊断再做一层传播判断。

先把问题拆开看：其中可能同时包含产品、价格、渠道、体验、信任、品牌认知、信息表达和触达效率。请判断哪些因素对结果影响最大，以及传播真正有能力改变其中哪一部分。

随后聚焦目标人群：
1）我们最希望哪一类人发生变化？为什么优先是他们？
2）他们现在如何理解这件事、通常会怎么做？
3）影响他们进一步行动的主要心理门槛、现实门槛和信息缺口分别是什么？
4）希望最终形成什么新的认知、感受与行为？
5）在哪些生活/购买/使用场景里，最容易产生注意和需求？
6）什么人、什么演示或什么证据最有机会建立信任？

输出一张【传播课题卡】：
目标人群 / 当前状态 / 目标状态 / 核心阻力 / 关键场景 / 最可信证据 / 传播可以贡献的业务结果。

最后给出一个直接、建设性的传播方向：我们建议优先通过【关键传播作用】推动【目标人群变化】，进而支持【业务结果】。
```

## 2｜品牌主张 + 核心创意 + 传播路径
```text
基于已确认的用户问题和业务目标，建立完整传播逻辑。

先形成核心信息结构【Message House】：
- 用户最终应该记住的一句话【核心主张】；
- 3 个支撑理由；
- 每个理由对应的真实证据【Proof】；
- 每个证据对用户意味着什么【Human Payoff】；
- 容易产生误读或需要保留限定条件的表达。

再发展核心创意【Big Idea】。至少提出 3 个真正不同的方向，每个方向都写清：
- 来自什么用户洞察或文化情绪；
- 为什么这个品牌有资格讲；
- 用户参与的理由；
- 如何延展到内容、活动、社媒、媒体与线下；
- 哪部分最有记忆点；
- 容易落入俗套的地方，以及如何优化。

用同一组标准比较：相关性、独特性、可证明性、延展性、可执行性、长期品牌价值。最后明确推荐一个，并说明取舍。

随后设计传播路径：注意 → 理解 → 相信 → 行动 → 分享/留存。
每一步说明：用户状态、传播任务、最合适的内容、渠道、表达主体、所需证据和下一步行为。

渠道选择必须回答“它在这一步具体完成什么任务”，形成互相接力的系统。
```

## 3｜传播运营系统 + 专业审稿
```text
现在把传播方向变成可以运行和复盘的系统。

【内容体系】
建立核心母内容、证明内容、场景内容、社交参与内容、转化内容、长期沉淀内容之间的关系。说明哪些素材可以复用、哪些必须为平台重新创作。

【媒体与创作者】
按传播角色分工：权威背书、技术解释、生活场景、文化参与、社群影响、转化与长期合作。给出选择标准、Brief 重点和验收方式。

【节奏】
把项目拆成用户状态变化的阶段。对每阶段说明：要解决什么、主要动作、进入下一阶段的信号、效果偏低时优先调整什么。

【预算】
解释资源为何投在这些环节。区分购买触达、建立可信度、生产资产、促进转化和沉淀长期能力。没有真实报价时提供预算逻辑与敏感性分析方法。

【指标】
同时建立传播结果、品牌结果和业务结果，并写出数据来源与复盘频率。

【风险与表达】
检查事实准确性、广告/隐私/版权/达人合规、文化语境、品牌承诺与真实体验的一致性，以及短期流量动作对长期品牌的影响。

最后以品牌传播负责人身份编辑一次整套方案：保留事实和判断，删除重复与空泛表达，优化逻辑过渡，让每个动作都能回到目标人群与业务目标。

最终回答：如果用户最终只记住一件事，我们希望他记住什么？为什么这件事值得记住？
```
