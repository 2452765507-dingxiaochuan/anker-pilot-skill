# 3C｜AI 内容生产 / 多平台 / 本地化（深度专业包）

**先读案例包**：`../references/scenario-case-packs/03-ai-content-cases.md`

## 适用题型
AI 辅助内容生产、多平台内容工厂、多语言本地化、营销素材提效、批量文案/视觉、品牌内容工作流。

## 最少需要的输入
产品/品牌事实源、目标人群、平台、内容目标、品牌语气、必须保留/禁止表达、可用视觉资产、语言/地区、审核与合规角色。

## A｜内容供应链设计
```text
读取 AI 内容案例包后，把本项目设计成一条可治理的【内容供应链】。

先定义：
- 单一事实源：产品参数、品牌主张、禁用表达、法律/合规；
- 输入 Brief 的必填字段；
- 母内容/母视觉是什么；
- 哪些步骤适合 AI，哪些必须由人做判断；
- 审核责任人和发布权限；
- 资产如何命名、版本化和复用。

输出流程图：需求 → 研究/事实 → Brief → 母创意 → 变体 → 本地化 → QC → 发布 → 数据 → 学习回写。

成功标准：AI 加速不会造成事实漂移、品牌走样和版本混乱。
```

## B｜母内容 + 多平台变体系统
```text
基于本次 Brief，先做一个高质量母内容：核心受众、使用场景、主要冲突/需求、核心信息、证据、CTA、品牌语气。

母内容确认后，再针对每个平台重新设计表达。对每个平台写：
- 用户为什么在这里看；
- 最适合的开头/首屏；
- 需要保留的核心证据；
- 适合的叙事长度与节奏；
- CTA；
- 平台原生元素；
- 与母稿相比具体改变了什么、为什么。

把“一稿多发”升级成“一个战略核心，多种平台原生表达”。
```

## C｜视觉生成 + 本地化 + 规模化生产
```text
视觉先确定一个清晰的 campaign art direction，再生成变体。请给 3 个不同方向并推荐一个：视觉概念、构图、人物/产品比例、场景、光线、材质、色彩、品牌识别、适合的渠道。

建立生成约束：产品外观不可错、Logo/文字如何处理、需要真实摄影时不使用 AI 替代、哪些素材必须来自官方资产。

本地化按“文化适配”处理：语气、幽默、人物、场景、单位、价格、节日、平台习惯和禁忌。标出必须由母语/当地市场复核的点。

批量生产前先通过 2–3 个样板，再扩展到 N 个版本，避免错误规模化。
```

## D｜四道 QC + 测试学习
```text
建立四道发布门槛：
1）事实：参数、数字、奖项、比较与限定条件；
2）品牌：信息层级、语气、品牌人格、视觉规范；
3）合规：版权、肖像、广告、平台、本地法规；
4）语言：自然、具体、没有空话和模板句，同时保留专业精度。

对同一目标生成少量真正不同的变体，并明确每个变体在测试什么假设。数据回来后只把有效学习沉淀进下一轮，不追求无限变体。

最终输出内容日历 + 资产清单 + 版本号 + 审核状态 + 指标 + 学习记录。
```

## E｜效率与质量成功标准
```text
用“速度、质量、品牌一致性、可追溯性、复用率”五个维度验收 AI 内容系统。可以计算：Brief→发布周期、一次通过率、返工率、母资产复用率、本地化周期、错误率、内容表现。

如果只有“写得更快、数量更多”，但审核更累或品牌更乱，说明流程仍需调整。
```

## 注意避免
- 一开始就批量生成，错误被规模化；
- 把“多平台适配”做成同一母稿机械缩写；
- AI 视觉改变真实产品外观、接口、尺寸或 Logo；
- 本地化只有直译，没有当地平台、文化、单位、价格和禁忌适配；
- 只统计产量和速度，不测返工率、事实错误和品牌一致性；
- 为了去 AI 味改动事实、确定程度或技术限定条件。
