# 3D｜整合营销 / 品牌战役（深度专业包）

**先读案例包**：`../references/scenario-case-packs/04-integrated-campaign-cases.md`

## 适用题型
新品/品牌 Campaign、联名、节日节点、赞助、文化事件、品牌破圈、整合传播、用户参与型战役。

## 最少需要的输入
业务目标、目标人群、产品/品牌证据、市场/地区、时间节点、预算或资源边界、已有渠道资产、最终交付要求。信息不全时先列缺口与可工作的假设区间。

## A｜案例迁移 + 战役机会判断
```text
先读取整合营销案例包，只提取与本题最相关的 3–4 个机制，不复述案例历史。

建立【战役机会地图】：
- 当前业务需要改变什么；
- 用户此刻有什么真实情绪、行为或文化张力；
- 品牌凭什么参与这个话题【Brand Right to Play】；
- 产品/技术有什么可以被证明的真实证据；
- 为什么是现在；
- 哪些社会/平台/节日/文化时刻可以成为放大器。

提出 3 个明显不同的机会区。每个机会区必须包含：
1）一句用户张力；
2）品牌扮演的角色；
3）最强产品/品牌证据；
4）用户为什么愿意注意或参与；
5）可形成的内容/事件；
6）能留下什么长期资产；
7）执行难点和不适用条件。

用【相关性、独特性、可参与性、可证明性、可延展性、执行难度、长期资产】同一套标准比较，并明确推荐一个。

成功标准：战役机会来自真实用户/文化张力与品牌资格的交集，主题和形式在此基础上自然生长。
```

## B｜Big Idea + 参与机制 + Campaign Architecture
```text
把选定机会发展成 3 个不同的【Big Idea】方向，再选择一个继续深入。

每个方向必须回答：
- 用户最终记住什么；
- 用户可以主动做什么、参与什么、表达什么；
- 品牌/产品为什么自然存在；
- 哪个画面/行为/符号能成为记忆锚点；
- 是否能跨 15 秒短视频、长内容、线下、媒体、零售和社媒继续生长。

选定后建立【Campaign Architecture】：
Hero：核心事件/内容/高点；
Hub：持续内容与用户承接；
Proof：产品、技术、第三方或真实体验证明；
Participation：用户/creator 如何参与和二创；
Conversion：官网、电商、门店、会员等业务承接；
Legacy：战役结束后留下什么品牌资产、用户资产、内容资产或组织方法。

同时输出一张“核心信息—关键证据—主要内容—渠道—CTA”关系表，避免各渠道各讲各的。

成功标准：一句话能说清创意，用户参与机制简单可懂，产品证据自然嵌入，所有模块围绕同一个核心思想。
```

## C｜渠道接力 + Creator / Media / Experience 分工
```text
现在设计完整传播接力，不做渠道清单。

按用户状态拆阶段：
尚未注意 → 愿意停留 → 理解 → 相信 → 参与/讨论 → 行动 → 分享/复访。

对每个阶段明确：
- 用户还缺什么；
- 最重要的信息/证据；
- Owned / Earned / Creator / Paid / Experience / CRM 分别承担什么任务；
- 内容格式；
- CTA；
- 进入下一阶段的信号。

Creator 进一步分为：专业解释者、生活方式使用者、文化参与者、转化型、真实用户。说明各自为什么可信、Brief 自由度、必须保留的证据和验收方式。

媒体部分给 3–5 个新闻切口，说明哪些能形成 earned media，哪些更适合品牌自有内容。

成功标准：每个渠道都有独立职责，前后能接力；减少“所有平台同步发同一条物料”的低效做法。
```

## D｜资产工厂 + 执行节奏 + 预算逻辑
```text
把战役变成可以执行和复用的【传播资产工厂】。

列出：Hero Film/主视觉、短视频母素材、产品 Proof、媒体资料包、creator Brief、UGC 模板、FAQ、零售/电商素材、CRM 素材、销售工具、案例复盘、用户洞察等。

对每类资产说明：
- 谁生产；
- 最晚何时完成；
- 依赖哪些上游信息；
- 可以被哪些渠道复用；
- 哪些渠道必须重新创作而不能简单裁切。

给完整时间轴：准备 → 预热 → 引爆 → 持续 → 长尾。标出关键依赖、审批节点、素材锁定日和备用方案。

预算不要机械平均分配。先说明最大预算应该解决哪一个核心瓶颈，再按内容制作、creator、媒体/公关、付费放大、体验/活动、技术/页面、监测和预备金给分配逻辑。

成功标准：团队能直接从时间轴和资产表开始执行；资源优先级与核心问题一致。
```

## E｜衡量 + 学习 + 最终交付验收
```text
建立六层指标：
1）文化/讨论：话题是否进入真实讨论；
2）内容质量：完播、保存、深度互动、有效评论；
3）品牌：认知、理解、信任、偏好、搜索；
4）参与：UGC/creator 参与、活动参与、复访；
5）业务：访问、线索、转化、销售、会员；
6）资产：可复用素材、媒体关系、用户洞察、长期内容系列。

每个指标写清：如何采集、它回答什么决策问题、什么趋势说明加码/调整/停止。

设计战役中的 3–5 个学习点，例如：核心主张、creator 类型、Proof、参与机制、首屏/CTA，并说明如何用数据改变下一阶段。

最终方案必须让评审一眼看到：机会洞察 → Big Idea → 参与机制 → 渠道接力 → 资产与执行 → 预算 → 指标 → 长期资产。

最后做一次完整性检查：如果删掉 Logo，创意是否仍然与品牌/产品高度相关？如果用户不参与，是否仍有价值？如果某个平台失效，系统是否有替代路径？
```

## 注意避免
- 追热点比用户问题更重要；
- slogan 很漂亮，但没有参与机制和产品 Proof；
- Paid / KOL / PR 只是并列预算项，没有用户路径；
- 开幕/发布日过度投入，战役后一周就失去内容；
- KPI 只有曝光和互动，没有品牌/业务变化；
- 把其他品牌的视觉形式直接复制，而没有迁移机制。
