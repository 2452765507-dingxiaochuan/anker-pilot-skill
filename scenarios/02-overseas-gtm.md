# 3B｜海外新品 GTM（深度专业包）

**先读案例包**：`../references/scenario-case-packs/02-overseas-gtm-cases.md`

## 适用题型
海外新品上市、市场进入、GTM、预售/众筹、跨境电商新品、区域市场推广、落地页与上市传播。

## 最少需要的输入
产品事实与价格、目标市场候选、目标用户、上市时间、渠道/库存/售后条件、预算或资源边界、竞品与已有品牌资产。缺失时先列证据缺口和验证优先级。

## A｜案例迁移 + 市场进入判断
```text
读取 GTM 案例包后，先整理 3–5 个对本题最有价值的机制：早期社会证明、分阶段上市、creator 本地化、渠道任务分工、评价形成、媒介与产品特性匹配等。

结合题目建立【市场进入判断】：
- 优先市场为什么值得进入；
- 核心人群是谁，现有替代方案是什么；
- 购买决策里最大的功能、价格、信任、渠道或使用门槛；
- 这个产品最适合用什么“可证明差异”切入；
- Why this market / Why now / Why this user / Why us 的证据分别是什么。

给 2–3 个市场/人群切入组合，并明确推荐一个。成功标准：市场选择和定位都有证据，不只因为“市场大”。
```

## B｜定位 + 证据 + 首批口碑系统
```text
建立新品的市场定位系统：
【一句话定位】/【核心场景】/【主要替代方案】/【3 个购买理由】/【每个理由的证明】/【主要顾虑与回答】。

设计首批可信口碑从哪里来：媒体评测、专业 creator、早期体验者、众筹/预售、零售体验、试用、已有用户迁移等。为每一类说明：为什么可信、需要什么 Brief、哪些事实可讲、如何避免统一口径显得像广告。

形成“技术/功能 → 用户结果 → 证据 → 第三方声音”的完整链路。

成功标准：用户在 30 秒内知道产品适合谁、解决什么、为什么值得多看一步；首批评价来源真实可执行。
```

## C｜上市阶段 + 渠道接力 + 本地化
```text
把上市设计成一系列用户状态变化，并让发布日期成为其中一个关键节点。

建议阶段：验证/种子期 → 预热 → Launch → 评价形成 → 放大 → 稳态。对每阶段写：
- 用户还缺什么；
- 最重要的传播任务；
- 渠道和 creator 的角色；
- 主要内容；
- CTA；
- 进入下一阶段的信号。

官网、电商、零售、科技媒体、YouTube、TikTok/短视频、社交、CRM 各自只承担最适合的任务，并写出如何接力。

本地化要检查：语言、价格表达、节日/文化、平台习惯、支付/配送、隐私广告政策、售后预期、creator 类型。统一全球核心信息，但允许本地表达机制不同。
```

## D｜经济性 + 供应履约 + 增长实验
```text
建立 GTM 经济模型：曝光→有效访问→考虑→购买→退货/留存，并列出需要的真实数据与计算公式。

同时检查库存、履约、客服、退换、评价响应、合规和价格体系能否承受推广量。如果任何环节容量不足，先给流量上限或分阶段放量方式。

设计 3–5 个优先实验，例如：定位文案、creator 类型、首屏证明、offer、landing page、评价素材；每个实验写假设、变量、主要指标、最小样本/观察周期逻辑、赢了以后怎么放大。

成功标准：方案既能创造需求，也能接住需求；知道什么时候加码、什么时候换素材、什么时候调整市场或库存。
```

## E｜最终产出成功检查
```text
最终 GTM 方案至少能让业务方直接看到：市场选择、定位、用户证据、首批口碑、上市节奏、渠道职责、内容/creator、本地化、预算逻辑、供应与售后依赖、指标、实验和调整信号。

检查每个动作是否对应一个明确用户状态变化。删除只有“加大曝光、铺 KOL、做矩阵”但没有任务和证据的表述。
```

## 注意避免
- 只因为市场规模大就优先进入；
- 全球统一素材直接翻译，忽略当地购买习惯和 creator 语言；
- 流量计划超过库存、客服、退换和售后承载能力；
- 首发阶段没有可信评价/第三方 Proof；
- 每个平台都承担从认知到成交的全部任务；
- 只写媒体预算，不写用户状态变化和实验学习。
